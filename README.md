# Computer Vision - Lab Task 01

This repository contains the required folder structure and scripts for Lab Task 01. 

## Directory Structure
* **Files/**: Contains the Python scripts.
* **Images/**: Contains sample images used by the scripts.

## `images.py` Description
The `images.py` script is located in the `Files` directory. It utilizes the OpenCV Python library (`cv2`) to load and display an image from the `Images` directory. The script dynamically navigates up one directory level to locate the image, reads it into memory, and opens a GUI window to display it until the user presses a key.
